# Sugestão de publicação

Estou desenvolvendo o Currículo Mais Rápido para resolver uma situação comum na busca por emprego: repetir as mesmas informações em cada candidatura.

A primeira versão permite importar um currículo em PDF, DOCX ou texto, revisar o perfil e gerar uma versão para PDF. Também inclui modos claro e escuro e uma extensão para preencher campos comuns de formulários, sempre com revisão antes de agir.

Na parte técnica, usei React e TypeScript na interface e Java com Spring Boot na API de extração. A demonstração processa os arquivos no navegador; a API pode ser utilizada na instalação completa.

Foi uma oportunidade de trabalhar com leitura de documentos, experiência do usuário, privacidade e integração com o navegador. A extensão ainda é instalada manualmente e a compatibilidade varia conforme o formulário.

Quero ouvir quem passa por isso na prática: qual etapa de uma candidatura mais consome o seu tempo?
