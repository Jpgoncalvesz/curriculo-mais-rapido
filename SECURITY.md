# Segurança e privacidade

Não publique credenciais, dados de currículos ou detalhes de falhas exploráveis em uma issue pública. Use o recurso de relato privado de vulnerabilidades do GitHub, quando habilitado pelo mantenedor. Caso esteja indisponível, abra uma issue sem detalhes sensíveis solicitando um canal privado.

O site padrão processa documentos no navegador. A API Java é opcional, sem autenticação ou persistência de perfis; sua configuração padrão atende desenvolvimento local. Para uso público, configure HTTPS, autenticação ou cotas, limites de requisição e tempo de execução, isolamento de processamento e atualização de dependências.

A extensão atua após clique, usa activeTab e não envia candidaturas. Revise os campos antes do envio. Os arquivos JSON exportados contêm dados pessoais e precisam ser guardados com cuidado.
